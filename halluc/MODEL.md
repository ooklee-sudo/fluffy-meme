# 검증 자원 배분 모형 (Cox-NHPP 위의 구간별 검증)

2026-10-28. 파일럿 증거(`RESULTS.md`)에 맞춰 세운 모형입니다. 증명은 핵심만 적었고, 원고화할 때 보강해야 합니다. 실증 평가는 §5, 코드는 `alloc_eval.py`입니다.

## 1. 설정

한 생성물(문서) d는 단위 t = 1..n_d (문장 또는 주장 묶음)로 이루어집니다. 각 단위에 오류 사건 Y_dt ∈ {0,1}이 있고 다음을 가정합니다 (파일럿에서 확인된 구조).

- **A1 (Cox 구조).** 잠재 변수 Θ_d = (Z_d, η_d) 조건에서 Y_dt는 독립이고 P(Y_dt = 1 | Θ_d) = p_dt = σ(f(t) + β′x_d + Z_d + η_dt). 여기서 f는 위치 프로필(비단조: 리드 높음 → 중반 최저 → 후반 반등), x_d는 관측 가능한 개체 특성(희귀도), Z_d ~ N(0, τ²)은 문서 수준 난이도, η는 국소 난이도(평균 0, 약한 상관)입니다.
- **A2 (전염 없음).** Y_ds가 Y_dt에 인과적으로 영향을 주지 않습니다. 관찰되는 상관은 Θ를 통해서만 생깁니다. (근거: 반사실 실험 `RESULTS.md` 4차, 95% CI 상한 +0.001)
- **A3 (검증).** 단위 t를 검증하면 비용 c_dt가 들고, 오류가 있으면 확률 δ로 발견해 수정합니다. 예산 B.

**목적.** 기대 잔여 오류 최소화, 곧 기대 포착 오류 Σ δ·E[p_dt]·v_dt 최대화 (v_dt ∈ {0,1}, Σ c v ≤ B).

## 2. 과대산포와 배분의 연결

**보조정리 1 (Fano 초과 = 잠재 강도의 공분산).** 창 W의 오류 수 N = Σ_{t∈W} Y_t, p̄_t = E[p_t | x]로 하면
 Var(N) = Σ_t p̄_t(1 − p̄_t) + Σ_{s≠t} Cov(p_s, p_t).

*증명.* A1에 의해 Var(N) = E[Σ p_t(1 − p_t)] + Var(Σ p_t). E[p(1 − p)] = p̄(1 − p̄) − Var(p)이고 Var(Σ p) = Σ Var(p_t) + Σ_{s≠t} Cov. 합치면 단위별 분산이 상쇄되고 공분산만 남는다. ∎

따라서 "관측 Fano − 독립 null"은 단위 고유의 변동이 아니라 **단위들이 공유하는 잠재 난이도의 크기**를 잰다. 이 공유 성분이 (i) 관측 특성으로 설명되는 부분은 정적 배분, (ii) 검증 결과로 학습할 수 있는 부분은 적응 배분의 이득 원천이다. 파일럿의 초과 Fano(w = 5: 27B 1.28 vs null 0.93)가 이 양이다.

## 3. 명제

**명제 1 (단일 지표 문턱 정책).** 비용이 같고 p̄_dt = h(f(t) + β′x_d)로 쓸 수 있으면(h(u) = E σ(u + Z)는 u에 증가), 정적 최적 정책은 u_dt = f(t) + β′x_d가 문턱 u* 이상인 단위를 검증하는 것이다. u*는 예산이 결정한다. 또한 f가 준볼록(quasi-convex)이면 각 문서에서 검증 집합은 **접두 구간 ∪ 접미 구간**이고, 예산이 늘면 두 구간이 안쪽으로 넓어진다. 문서 간에는 β′x_d가 큰 문서일수록 더 많이 검증한다.

*증명.* 목적함수는 v에 선형이고 비용이 같으므로 최적은 p̄ 상위 B개이며(분수 배낭 문제의 탐욕 해), h가 증가함수라 p̄ 순위는 u 순위와 같다. f가 준볼록이면 {t : f(t) ≥ c}는 구간의 여집합이다. ∎

*(비용이 같지 않으면 순위는 p̄/c이다. 이 경우 접두·접미 구조는 일반적으로 성립하지 않는다.)*

**명제 2 (표적 검증의 가치는 이질성에 대해 Schur-볼록).** 단위 수 N, 비용 1, 예산 k일 때 정적 표적 정책의 이득 G_k(q) = δ[Σ_{상위 k} q_i − (k/N) Σ q_i]는 q(= p̄)의 합이 같을 때 q가 다른 q′를 majorize하면 G_k(q) ≥ G_k(q′)이다. 모든 q_i가 같으면 G = 0이다.

*증명.* 상위 k개의 합은 모든 k-부분집합의 합의 최대이므로 대칭 볼록 함수이고, 따라서 Schur-볼록이다. 두 번째 항은 합이 같으면 상수이다. ∎

해석: 평균 환각률이 같아도 **오류 강도가 불균등할수록 검증을 표적화하는 가치가 커진다.** "환각률 한 숫자"가 배분 결정에는 부족한 이유다.

**명제 3 (문서 내 적응성은 무가치, 이득은 문서 간에서만).** 비용이 같고 A1이 성립하면, 한 문서 안에서 검증 결과로 Z의 사후분포가 어떻게 바뀌어도 사후 예측확률 q_dt(o) = E[σ(f(t) + β′x + Z) | o]는 f(t)에 대해 증가하므로 문서 내 단위의 **순위는 변하지 않는다.** 따라서 문서별 예산이 고정이면 적응 정책의 기대 포착량은 정적 정책과 같다. 예산을 문서 간에 공유할 때만 적응적 재배분이 이득을 낼 수 있다.

*증명.* 사후분포가 고정되면 q는 f(t) + β′x의 증가함수의 기댓값이다. 같은 문서의 단위들은 β′x와 사후분포를 공유하므로 f(t)의 순서가 곧 q의 순서이다. 문서 간 비교는 사후 평균 난이도에 의존하므로 순위가 바뀔 수 있다. ∎

*(η가 국소적으로 상관되어 있거나 비용이 단위마다 다르면 이 결론은 약해진다. 본 연구에서는 η 구조를 직접 추정하지 않았다.)*

**명제 4 (적응 정책의 하한).** 정적 정책은 적응 정책의 특수한 경우이므로 최적 적응 정책의 기대 포착량 ≥ 정적 정책의 기대 포착량이다. 또한 q_dt(o)는 o에 대해 martingale(E[q_dt(o)] = p̄_dt)이다. 순위가 바뀔 확률이 양수인 경우(문서 간 예산 공유 + τ > 0)에만 엄밀한 부등호가 가능하다.

*(Bayes-greedy가 최적이라는 주장은 하지 않는다. 실험에서는 탐욕 정책을 사용했다.)*

## 4. 모형이 예측하는 것 (사전 가설)

1. 정적 표적이 균등 배분보다 크게 낫다 (명제 2, 이질성이 있으므로).
2. 문서별 예산이 고정이면 적응형 = 정적형 (명제 3).

## 6. 한계 (원고에서 반드시 다룰 것)

1. **판정이 곧 진실이 아님.** 오류 라벨은 위키 본문 기준의 LLM 판정이다. 검증자(사람)의 발견율 δ와 판정 오류는 별개이며 δ = 1은 이상화다.
2. **단위 크기 인공물.** 리드 문장은 주장이 많아 "하나라도 틀리면 사건"에서 유리하다. 비용 보정으로 크기를 줄여 보였으나, 단위를 주장 수준으로 정의한 분석은 별도로 필요하다.
3. **도메인.** 위키 기반 전기 생성(희귀 인물 중심)이다. 질의응답, 요약, 추론에서의 λ(t)와 τ는 다를 수 있다. 일반화하려면 해당 도메인에서 f와 τ를 다시 추정하면 되는 구조이지만 아직 하지 않았다.
4. **전염 가정(A2)의 범위.** 반사실 실험은 모델 1개, "이어 쓸 글" 접두부 설정이다. A2가 깨지면 명제 3이 약해지고 앞당김 효과가 생긴다.
5. **정책 최적성.** 적응 정책은 탐욕이며 최적이 아니다. 최적 순차 정책은 열린 문제이다.

# 8. IS 맥락 확장: 검증 여부의 결정과 2단계 검증 (2026-10-28)

앞 절들은 "예산이 주어졌을 때 어디를 볼까"였습니다. 여기서는 예산을 선택 변수로 두고 오류의 손실을 넣어 "검증을 할 것인가, 얼마나, 어떤 기술로"를 다룹니다. 사용자(조직)가 LLM 출력의 각 단위에 대해 검증 여부를 정하고, 검증 기술이 한 종류 이상일 때입니다.

## 설정
단위 t의 위험 q_t(공개 신호로 예측한 오류 확률, §1~§3의 p̄), 검증 비용 c, 검증이 오류를 발견·수정할 확률 δ, 미발견 오류의 손실 L. 계획 v ∈ {0,1}^T의 기대 비용 C(v) = Σ c·v_t + Σ L·q_t·(1 − δ·v_t).

## 명제 5 (뉴스벤더형 문턱과 표적화의 가치)
(a) 최적 규칙은 δ·L_t·q_t ≥ c_t인 단위만 검증하는 것이다. (b) a_t = δ L q_t − c라 하면 최적 정책의 기대 절감은 Σ a_t⁺이고, 무작위로 일정 비율을 검증하는 정책은 비율에 선형이므로 최선이 "전부" 또는 "없음" 중 하나이며 그 절감은 (Σ a_t)⁺이다. 따라서 **표적화가 균등 배분에 더하는 가치는 V = Σ a_t⁺ − (Σ a_t)⁺ = min(Σ a_t⁺, Σ a_t⁻)** 이다. (c) V = 0 ⇔ 모든 a_t의 부호가 같다(전부 검증할 가치가 있거나 전부 없다).

*증명.* 비용이 v에 대해 분리 가능하고 선형이므로 (a)는 단위별 비교이다. 균등 정책의 기대 비용은 비율 φ에 대해 선형이므로 최솟값은 φ ∈ {0, 1}에서 나오고, 그 절감은 max(0, Σ a_t)이다. Σ a⁺ − (Σ a⁺ − Σ a⁻)⁺ = min(Σ a⁺, Σ a⁻). ∎

해석: 가치는 **"검증할 가치가 있는 단위들의 총잉여"와 "검증할 가치가 없는 단위들의 총낭비" 중 작은 쪽**입니다. 위험이 균일하면 0이 되고(§3 명제 2와 같은 결론), 손실 대 비용 비 L/c가 너무 작거나 너무 크면 한쪽 합이 0으로 가서 역시 0이 됩니다. 표적화는 L/c가 중간 범위일 때, 곧 손익분기 위험 c/(δL)이 q의 분포 안쪽에 들어올 때만 가치가 있습니다.

## 명제 6 (자동 검사 후 사람 검증)
1단계 자동 검사(비용 c₁, 오류를 플래그할 확률 δ₁, 정상 단위를 잘못 플래그할 확률 f₁, δ₁ > f₁)가 있고, 플래그된 단위만 사람이 확인(비용 c₂, 발견율 δ₂)한다고 하자. 위험 q인 단위의 순가치는 없음 N(q) = 0, 사람만 H(q) = δ₂Lq − c₂, 선별 후 사람 S(q) = δ₁δ₂Lq − c₁ − c₂[qδ₁ + (1−q)f₁]이다. 세 직선의 기울기는 0 < S의 기울기 < H의 기울기(δ₂L)로 정렬되므로 최적 행동은 q가 커질수록 **없음 → 선별 후 사람 → 사람 직접** 순서의 구간 구조이다. 선별 구간이 비어 있지 않을 필요충분조건은
 **c₁ < c₂ (δ₁ − f₁)(1 − q_h),  q_h = c₂/(δ₂ L)**.

*증명.* 세 직선의 상계 포락선. N과 H의 교점이 q_h이고 선별 직선이 그 점에서 양수여야 중간 구간이 생긴다. S(q_h) = c₂(δ₁ − f₁)(1 − q_h) − c₁. ∎

해석: **"AI가 AI를 검증"하는 값싼 자동 검사는 변별력(δ₁ − f₁) × 정상 단위에서 아끼는 사람 비용(c₂(1 − q_h))이 검사 비용 c₁을 넘을 때만 쓸모가 있다.** 위험이 높은 단위는 선별을 거치지 말고 바로 사람이 확인해야 합니다(선별이 놓치는 오류의 손실 때문).

## 수치 예시 (`is_model.py`, `results/is_model.txt`)
교차적합한 위험 q(내용 특징 모형)와 실제 오류 라벨로 실현 비용을 계산했습니다. c = 1, 무검증/전체검증 중 나은 쪽 대비 표적 규칙의 절감.

| L/c | 전기 gemma-27b, δ=1 | 전기 δ=0.8 | 요약 gemma-27b, δ=1 | 요약 mistral-small, δ=1 |
| --- | --- | --- | --- | --- |
| 2 | 5.1% | 2.8% | 0.0% | 0.0% |
| 3 | 14.2% | 6.3% | 0.0% | 0.1% |

## δ 민감도 (`delta_sweep.py`, `results/delta_sweep.txt`)
- 정적 정책의 이득은 δ에 선형입니다(구성상). 전기 gemma-27b에서 δ = 1.0 → 0.4로 가면 균등 대비 정적 이득이 0.266에서 0.106으로 줄어듭니다.
- 적응형(공유 예산)의 정적 대비 이득은 δ가 낮을수록 사라집니다. 전기 gemma-27b, 예산 50%에서 +0.037 [+0.008, +0.062](δ=1) → +0.030(0.8) → +0.015(0.6) → +0.006 [−0.001, +0.012](0.4). 검증 결과가 덜 확실하게 관찰되므로 Z를 학습하기 어렵기 때문입니다. 요약에서는 모든 δ에서 0과 구분되지 않습니다.
- 따라서 **불완전한 검증자(δ < 0.6)에서는 적응 재배분의 가치가 거의 없고, 정적 표적화가 실용적인 선택**입니다.

- L, c는 가정한 모수입니다. 실제 조직의 손실 분포와 검증 비용은 확인하지 못했습니다. 명제 5·6은 구조적 결론이고 크기는 모수에 달려 있습니다.

- 사람 검증자의 인센티브(노력의 관측 불가능성)는 다루지 않았습니다.

## 명제 6의 모수 예시: 판정자 간 불일치로 어림한 자동 검사의 변별력

판정자 B를 기준으로 삼고 판정자 A를 "값싼 자동 검사"로 보면(`results/judge_agreement_*.txt`), A의 발견율 δ₁ = P(A 플래그 | B 플래그), 오경보율 f₁ = P(A 플래그 | B 비플래그)는 다음과 같다. **B는 정답이 아니므로 어림값일 뿐이다.**

| | δ₁ | f₁ | 변별력 δ₁ − f₁ |
| --- | --- | --- | --- |
| 전기 (모순) | 0.636 | 0.072 | 0.564 |
| 요약 (지지되지 않음) | 0.230 | 0.081 | 0.149 |

손실 대 사람 검증 비용 L/c₂ = 5, 사람의 발견율 δ₂ = 1이면 q_h = c₂/(δ₂L) = 0.2이다. 명제 6의 조건 c₁/c₂ < (δ₁ − f₁)(1 − q_h)에 대입하면
- 전기: c₁/c₂ < 0.564 × 0.8 ≈ **0.45** — 자동 검사 비용이 사람 검증 비용의 45% 미만이면 선별이 이득.
- 요약: c₁/c₂ < 0.149 × 0.8 ≈ **0.12** — 자동 검사가 사람 검증의 12% 미만의 비용이어야 이득. 변별력이 낮아 사실상 거의 공짜여야 한다.

요점: **같은 "LLM 판정자"라도 과제에 따라 선별 도구로서의 가치가 크게 다르다**(요약에서는 판정자끼리도 같은 문장을 잘 못 가려낸다). 모수는 L/c₂, δ₂에 따라 바뀌며 위 값은 한 점의 예시다.

## 10.2 명제 6의 확장: AI 표시에 대한 사람의 의존

Si 등(2023)은 AI 설명이 있을 때 정확도가 AI의 정확성에 따라 크게 달라지고(맞을 때 0.87, 틀릴 때 0.35), 시간은 줄어든다(2.53분 → 1.01분)고 보고합니다. 이를 모형에 넣습니다.

- 직접 검증: 비용 c₂ = 1, 발견율 d_H = 0.73.
- 표시된 단위 검토: 비용 c_A = 1.01/2.53 ≈ 0.40, AI 표시가 맞을 때 발견율 d_A = 0.87, **AI가 틀렸을 때(정상 문장에 잘못 붙은 표시) 사람이 표시를 받아들일 확률 0.65**, 이때 손실 λ·L.
- 순가치: N = 0, H = d_H L q − 1, S = δ₁ d_A L q − ρ − c_A[qδ₁ + (1−q)f₁] − λ L (1−a_w)(1−q) f₁ (a_w = 0.35).
- 이 확장에서는 S의 기울기가 H의 기울기보다 커질 수 있어(δ₁ d_A > d_H이면), 원래 명제 6의 영역 순서(없음 < 선별 < 직접)가 **깨집니다.** 높은 위험 단위에서도 선별 후 검토가 직접 검증을 이길 수 있습니다. 순가치 선분의 상계 포락선이라는 증명 구조는 그대로이며, 영역의 순서만 모수에 따라 달라집니다.

판정자의 실제 플래그와 사람 라벨로 계산한 실현 비용(FActScore 주석 3,515~3,628문장, 판정자 자체의 δ₁ = 0.88~0.94, f₁ = 0.23~0.31를 사람 라벨로 측정):

- 문헌값(c_A = 0.40, d_A = 0.87) 아래에서는 3영역 규칙의 선별 비중이 95~100%이고, 선별 없는 최선(무검증 / 사람 직접 / 위험 기반 사람 직접) 대비 비용이 **약 15~57% 낮습니다**(ρ 0~0.2, λ 0~0.5, L/c 3~12의 표본 칸 기준).

**그러나 이 결과는 견고하지 않습니다.** 두 문헌값을 바꾼 민감도(ρ = 0.10, λ = 0.25, Haiku; 선별 없는 최선 대비 절감):

| c_A \ d_A | 0.87 | 0.73 | 0.60 |
| --- | --- | --- | --- |
| 0.40 | 44% / 42% / 37% / 33% / 28% | 27% / 21% / 11% / 2% / −9% | 12% / 2% / −13% / −27% / −42% |
| 0.70 | 29% / 31% / 28% / 26% / 23% | 12% / 10% / 2% / −5% / −14% | −3% / −9% / −22% / −34% / −47% |
| 1.00 | 14% / 19% / 19% / 19% / 18% | −3% / −2% / −7% / −12% / −19% | −18% / −21% / −31% / −41% / −52% |

(각 칸은 L/c = 3, 5, 8, 12, 20의 절감.)

- **선별의 이득은 "AI 표시가 사람의 정확도를 올린다"는 가정(d_A = 0.87 > d_H = 0.73)에 크게 의존합니다.** 표시가 정확도를 올리지 못하면(d_A = 0.73) 이득은 검토 비용이 낮을 때(c_A ≤ 0.4~0.7)와 L/c가 작을 때(≤ 8)만 남고, d_A = 0.60이면 선별은 손해입니다.
- Si 등의 **전체** 정확도는 설명 조건 0.74, 검색 조건 0.73으로 거의 같습니다(AI가 맞을 때의 이득이 틀릴 때의 손실과 상쇄됨). 0.87은 AI가 맞은 경우의 값이라, 위 모형에서 d_A = 0.87은 낙관적 상한입니다. **문헌이 안정적으로 지지하는 것은 시간 절감(검토 비용 c_A)이며, 정확도 향상은 지지하지 않습니다.**
- 따라서 지금 말할 수 있는 것: **"AI가 표시해 주면 사람의 검증이 빨라지는 효과(문헌에서 약 60%)만으로도, 표시의 품질이 사람 정확도를 해치지 않는 한, L/c가 작은 영역에서 선별이 이득이다."** 선별이 항상 지배적이라는 주장은 할 수 없습니다.

## 10.3 한계

- 문헌 모수(Si 등)는 위키 기반 짧은 주장의 참/거짓 판정 과제이고 우리 단위(문장)와 다릅니다. 정확도를 오류 발견율로 쓴 것은 근사입니다. 수치는 도구가 정리한 본문 요약에 기반하며 투고 전 원문 표와 대조해야 합니다.
- 선별 후 검토에서 선별이 놓친 오류(플래그 없음)는 사람이 보지 않는다고 가정했습니다. Si 등에서는 사람이 모든 주장을 AI 설명과 함께 봅니다.
- 손실 L, 자동 검사 비용 ρ, 잘못 교정하는 해악 λ는 문헌 근거 없는 격자 값입니다.
- 판정자는 위키 본문(근거)을 보고 판정했습니다. 근거가 없는 상황에서는 δ₁, f₁이 낮아질 것이고 선별의 가치도 줄어듭니다.
