## 규정 확인 상태 (Elsevier 가이드 페이지는 이 환경에서 열리지 않음)
- **검색으로 확인:** 이중 익명 심사(제목 페이지 별도 파일), 편집 가능한 Word 또는 LaTeX 파일(PDF 불가), 초록 250단어 이하, 생성형 AI 사용을 원고 끝에 선언, 영어 철자 통일.
- **미확인 (Elsevier 통상 기준을 적용):** Highlights 3-5개 85자 이하, 키워드 개수, 참고문헌 형식(원고의 INFORMS 저자-연도 형식 유지), 분량 제한. **제출 전 가이드 페이지에서 확인하세요.**

## 제출 전에 채울 것
1. 제목 페이지와 커버레터의 `[ ]` 항목 전부.
2. 본문 끝 "Declarations"의 **생성형 AI 사용 선언**: 도구와 용도를 사실대로 적어야 합니다.
3. 데이터·코드 공개 DOI.
4. 참고문헌의 이탤릭(저널명)은 PDF 추출 과정에서 사라졌습니다. 최종 형식에 맞춰 손봐야 합니다.
5. 수식 3개는 Word 수식으로 들어가 있습니다. LibreOffice에서는 안 보일 수 있으니 Word에서 확인하세요.

## ISR 원고에서 바뀐 점
- 초록: 250단어 이하로 재작성, 일 단위 출시 반응은 "exploratory"로 표시.
- Introduction: 기여 문단을 I&M 독자(실무·거버넌스) 중심으로 교체, 일 단위 결과를 탐색적이라고 명시.
- 4.1: 표본 선정의 영향(느리게 릴리스하는 프로젝트 제외)과 해석 범위 문장 추가.
- 5.6: Table 2(동등성 검정 요약) 추가 (원고의 수치만 사용).
- 6장: 6.2 연구 시사점, 6.3 실무·정책 시사점, 6.4 한계와 향후 연구로 재구성. 외적 타당도 문단 확장, 향후 연구 문단 추가.
- 원고의 수치와 결과는 바꾸지 않았습니다.
