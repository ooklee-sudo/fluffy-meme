# 가장 가까운 선행연구 비교: Winter, Zacharias & Hartwig (2026)

Winter, C. G. H., Zacharias, N. A., & Hartwig, M. (2026). Using LLMs as sentiment analyzers to predict review helpfulness: first insights to open the black box. *Marketing Letters*, 37, Article 30. https://doi.org/10.1007/s11002-026-09824-7 (CC BY 4.0)

읽은 범위: 본문 14쪽(저자 공개본, DFKI 호스팅). Web Appendix 1–5(모형 사양, 벤치마킹, GPT-5-nano 재분석, 매개모형)는 **읽지 못함**. 인용 전 원문과 부록으로 재확인할 것.

## 논문 요약
- **질문**: RQ1 LLM이 리뷰 텍스트에서 별점(의도한 평가)을 얼마나 정확히 맞히는가(쾌락재/실용재에 따라 다른가). RQ2 LLM 분류와 실제 별점의 **괴리**가 helpful votes를 낮추는가(탐색재/경험재 조절).
- **데이터**: 12개 제품 검색어의 첫 페이지 상품 리뷰 28,900건(글로벌 소비자 플랫폼). 제품 유형은 Kübler 외(2024) 분류.
- **LLM 사용**: GPT-4, 시스템 프롬프트로 "텍스트로 별점 추정", temperature 0.2, 제로샷. 강건성으로 GPT-5-nano. 측정 변수는 **하나**(|실제 별점 − LLM 추정 별점|).
- **종속변수·모형**: helpful votes(0이 15,529건 = 54%), **Tobit(0에서 좌측 절단)**, 상품(ASIN) 단위 클러스터 SE. 통제: 길이, 별점 더미, 이미지/영상, 리뷰 나이, 리뷰 수.
- **실험**: Prolific 1,063명, 400개 리뷰 층화 표본. 독자가 추정한 별점의 괴리를 매개변수로 한 조절된 매개.
- **결과**: LLM-별점 상관 r=.763, 37% 불일치. Study 2 직접효과 n.s.(β=−.650, p=.428), 경험재 상호작용 음(β=−7.239, p<.001). Study 3 실험은 **조절 방향이 반대**(탐색재에서 효과가 더 큼). 저자도 모호하다고 인정.
- **저자가 밝힌 한계**: 특정 LLM 버전, 제로샷만(미세조정 없음), 메커니즘(처리 부담)을 직접 검증 못 함, 시간 경과에 따른 별점 의미 변화.

## 우리 연구와의 차이
| 축 | Winter 외(2026) | 우리 연구 |
|---|---|---|
| 측정하는 것 | **단일 지표**: 텍스트-별점 불일치(= 일관성의 대리변수) | **다차원 내용 특성**(구체성, 정보성, 논지균형, 서사, 감정 등 9개) |
| LLM 오류의 역할 | LLM의 오분류 **자체가 신호** | LLM 오류는 **측정오차**(보정 대상) |
| LLM 타당화 | 별점과의 상관만(r=.763), 인간 코딩 검증 없음 | 인간 코딩 + 코더 간 신뢰도 + 교차 모델 |
| 측정오차 보정 | 없음 | DSL/PPI 계열 보정 |
| 종속변수 모형 | Tobit(좌측 절단) | 음이항/포아송 + 노출 offset |
| 비교 baseline | 별점 분류에서 TF-IDF/XGBoost 등과 비교(부록) | 유용성 count 예측에서 사전/임베딩과 비교 |
| 탐색재/경험재 | 12개 제품, 현장-실험 불일치 | 카테고리 2개(식품 vs 전자제품), 아직 효과 없음 |
| 실험 | 독자 실험 있음(매개) | 없음 |
| 현재 증거 | 경험재 상호작용 유의(현장 데이터) | 파일럿에서 LLM 변수 효과 불안정, H3 효과 없음 |

## 시사점
1. **겹침은 중간 수준**: 같은 종속변수, LLM, 탐색/경험재 조절을 쓰지만, 측정 대상(불일치 vs 내용 특성)과 방법(Tobit vs count + 보정)이 다름. "LLM이 유용성을 예측한다"는 일반 서사는 이미 선점됨.
2. **쓸 수 있는 차별점**
   - 다차원 내용 특성 + 이론 기반 코드북.
   - count 모형의 정당화: 0이 54%인 데이터를 Tobit(연속 잠재변수 가정)으로 다루는 것은 논쟁 여지가 있음. 우리는 음이항/영과잉으로 비교 가능.
   - LLM 측정오차 보정: 저자들이 한계로 인정한 "LLM 한 버전, 제로샷"에 대한 보완(다중 LLM, 인간 라벨 검증).
3. **분석에 반영할 것**: 텍스트-별점 불일치(|별점 − LLM 추정|)를 통제/탐색 변수로 추가하면 직접 비교와 재현이 가능하다. 이 논문의 현장 데이터 결과(경험재 상호작용 유의)를 우리 Amazon 표본에서 재현해 보는 것이 가장 정직한 첫 확인이다.
4. **투고처 신호**: LLM 측정 + 유용성 연구가 *Marketing Letters*에 실렸으므로, 같은 계열의 짧은 형식 저널은 현실적인 후보이다.
