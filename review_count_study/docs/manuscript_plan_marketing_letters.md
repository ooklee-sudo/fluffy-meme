# 원고 설계안: Marketing Letters (짧은 형식)

> 규정은 웹 검색 결과(Springer 투고 안내 일부)에 근거한 것이다. **투고 전 https://link.springer.com/journal/11002/submission-guidelines 에서 직접 재확인**할 것. 특히 Replication Corner가 현재도 운영되는지, 단어 수 산정 방식을 확인.

## 1. 형식 선택
| 유형 | 분량 | 표·그림 | 비고 |
|---|---|---|---|
| 일반 논문 | 5,000단어 (초록 150단어 이내 + 본문 + 참고문헌 포함) | 최대 4개 | 온라인 부록 2,000단어 별도 |
| Replication Corner | 4,000단어 (동일 산정) | 최대 3개(단어 수에 불포함) | 재현·확장 논문용 |
| Idea Corner | 1,500단어 | 1개, 참고문헌 10개 | 아이디어 제안 |

**권고**: 이 연구는 Winter 외(2026)의 재현·확장이므로 **Replication Corner**가 자연스럽다. 결과가 재현되지 않거나(재현 실패), 재현되면서 새 조건(count 모형, 여러 제품 유형, 여러 LLM)에서 일반화되는 경우 모두 해당. 결과가 모호하면 일반 논문 대신 부록 기반 보강이 필요. **결과를 본 뒤 확정.**

## 2. 투고 요건 (데이터·코드 정책)
- 저널 정책상 데이터 수집 자료, 데이터, 분석 코드를 **심사팀과 독자가 접근할 수 있게 문서화**해야 하고, 데이터는 게재 후 **최소 10년 보존**. 독점 데이터는 편집자 재량으로 예외.
- 우리 상황: Amazon Reviews 2023은 공개 데이터이나 원문 재배포는 조건이 불분명. **리뷰 ID 목록 + 샘플링 코드 + LLM 응답(별점 추정값) + 분석 코드**를 공개하고 원문은 공식 출처에서 직접 받도록 안내. 이 방식이 저널 정책을 충족하는지 투고 시 편집자에게 확인.
- 사전등록(aspredicted.org) 권장. 아래 4절 초안 참고.
- 원 논문 저자에게 프롬프트·R 스크립트 요청 또는 기술 부록 확인(원 논문은 기술 부록에 R 스크립트와 프롬프트를 수록했다고 밝힘). 같은 프롬프트로 재현해야 "엄밀한 재현"이 된다.

| 절 | 단어 | 내용 |

표(3개 이내): 표1 Study 1 일치도·괴리 요약, 표2 Study 2 Tobit와 NB2 병렬, 표3 강건성(ZINB·클러스터·LLM 변형). 부록(2,000단어): 프롬프트, 재현 스크립트 설명, 추가 사양.

## 4. 사전등록 초안 (AsPredicted 항목)
1. **데이터 수집 상태**: 2,000건 파일럿(탐색 목적)은 이미 분석해 결과를 보았다. 본 분석용 약 26,000건은 수집 및 LLM 호출은 완료되거나 진행 중이나 **결과를 확인하지 않은 상태에서 등록**한다. (이 진술은 등록 시점에 사실이어야 함.)
2. **가설**: H1 |저자 별점 − LLM 추정 별점|(괴리)은 helpful vote 수와 음의 관계. H2 괴리×경험재 상호작용은 음(경험재에서 더 큰 감소). H3 위 결론은 음이항 모형에서도 유지.
3. **종속변수**: helpful_vote(비음 정수).
4. **조건/핵심 변수**: 괴리(연속), 경험재 더미(뷰티·주방 = 1, 휴대폰·사무용품 = 0; 카테고리 단위 분류는 우리의 가정).
5. **분석**: (a) 원 논문과 같은 Tobit(0에서 좌측 절단), 상품(parent_asin) 클러스터 SE, 통제: 글자 수, 별점 더미(1점 기준), 이미지, 리뷰 나이. (b) 음이항(NB2), log(리뷰 나이) offset, 동일 통제. (c) ZINB. 판정 기준: 괴리와 상호작용 계수의 양측 p<.05, 방향 일치 여부.
6. **이상치**: 제거하지 않음. 텍스트가 비어 있거나 LLM 응답 실패 행만 제외.
7. **표본 크기**: 4개 카테고리에서 각 6,500건 추출 후 중복·실패 제거(약 25,000). 사용자당 최대 5건.
8. **기타**: 사용자 단위 클러스터를 강건성으로 보고. 다른 LLM으로 괴리를 재계산하는 강건성 분석은 탐색적으로 표시.

## 5. 해야 할 일 (순서)
1. [진행 중] 2.5만 건 별점 추정 및 분석 실행 — **사전등록을 하려면 결과를 보기 전에 등록**한다.
2. 사전등록 제출(연구자 본인 계정).
3. 결과 확인 → Replication Corner vs 일반 논문 확정.
4. 다른 LLM(예: 다른 계열 모델)로 괴리 재추정(강건성), 프롬프트 변형.
5. 원 논문 저자에게 프롬프트와 R 스크립트 확인.
6. 데이터·코드 공개 패키지 준비(리뷰 ID, 별점 추정값, 코드).
7. 원고 작성, 단어 수 점검.
