I am pleased to submit the manuscript "Same Model, Different Shortcuts: How Prompt Layout Steers LLM Operators to Skip Verification" for consideration as a Feature Article (general submission) in *IEEE Intelligent Systems*.

Organizations are beginning to let large language model (LLM) agents run operational pipelines, including the decision to skip regression tests. The manuscript asks which features of the prompt that delegates such a decision make an LLM operator take this shortcut when it is clearly the worse choice. In a rule-scored maintenance task, with every status message written in 16 independently generated wordings and the options presented in all six orders, we recorded more than 38,000 decisions from 11 models. Four findings stand out: stating the quality target, not describing a loss, raised skipping; the order of the options mattered as much as the wording, and the order that triggered skipping differed across models, so a single test layout can make a risky model look safe; larger models never skipped; and enabling reasoning together with stating each option's expected value removed skipping in a fast model. We close with an audit procedure that organizations can run before delegating decisions to an AI operator.

The manuscript fits the magazine's interest in AI engineering and best practice, human-machine cooperation, and AI trust. It is written for both experts and nonexperts, and it stays within the limits for peer-reviewed papers (about 5,100 words counting figures and tables at 300 words each, a 149-word abstract, and 16 references).
