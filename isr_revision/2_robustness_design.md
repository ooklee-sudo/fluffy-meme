# 2. 규모·강건성 확대 설계 (Study 2: 사전등록 확증 실험)

이 문서는 `agent_econ` 시뮬레이터에 넣을 설계 명세입니다. 아직 실행하지 않았고, 비용과 검정력은 맨 아래 절에 기존 144 월드 로그에서 계산한 값을 적었습니다.

## 설계 원칙

- 각 요인은 P1′–P5′의 반증 조건에 직접 대응하는 것만 둡니다.
- 전체 완전 요인설계는 월드 수가 폭증하므로 **세 블록**으로 나눕니다.
- 모든 블록에서 같은 결과 변수와 같은 분석 코드(`analysis/`)를 씁니다.

## 블록 A — 핵심 재현 (P1′, P2′, P3′)

| 요인 | 수준 |
|---|---|
| authority | binding / advisory |
| office rent | 0 / 2 |
| 사익 프레이밍 | 중립 / 사익 현저 (자기 에너지 최대화 목표 명시) / 집단후생 현저 |
| 모델 구성 | 기존 3종 (Claude만 / DeepSeek만 / 혼합) |
| 시드 | 6 |

월드 수: 2 × 2 × 3 × 3 × 6 = **216**. 선거 규칙은 기존 결과가 null이므로 plurality로 고정합니다.

## 블록 B — 규모와 전략적 깊이 (P4′)

| 요인 | 수준 |
|---|---|
| 에이전트 수 | 6 / 12 / 24 |
| 추론 | 비활성 / 활성 |
| 선거 규칙 | plurality / ranked-choice |
| authority | binding 고정, rent = 2 고정 (경쟁이 일어나는 조건) |
| 모델 | 혼합 구성 (두 계열 반반) |
| 시드 | 6 |

월드 수: 3 × 2 × 2 × 6 = **72**. 과제 수는 에이전트 수에 비례(에이전트 3명당 1과제)해 희소성 비율을 유지하고, 별도 시드 6개로 희소성 비율 (1/3 → 1/6)을 바꾼 월드 18개를 추가합니다. 합계 **90**.

## 블록 C — 모델·샘플링 강건성 (P5′)

| 요인 | 수준 |
|---|---|
| 모델 계열 | 최소 4개 (기존 2개 + 다른 폐쇄형 1개 + 오픈웨이트 1개) |
| 능력 대비 | 같은 계열 내 소형/대형 쌍을 계열마다 최소 2개 |
| temperature | 0.7 / 1.0 |
| 고정 | binding, rent = 2, 중립 프레이밍 |
| 시드 | 6 |

월드 수: 모델 구성 8 (계열 4 × 혼합 쌍 포함, 실제 조합은 모델 접근에 맞춰 조정) × 2 × 6 = **96**.

**합계: 216 + 90 + 96 = 402 월드.** 기존 168과 합치지 않고 별도 연구로 보고합니다.

## 사전등록에 적을 것

1. 확증 가설: P1′–P5′와 각각의 반증 조건 (`1_theory_reframing.md`).
2. 1차 결과 변수: 출마 없는 선거 비율, Gini, 통제 기간(longest holder spell), 승리 확률(출마 조건부).
3. 분석 모형: `analysis/analyze_worlds.py`의 요인 모형과 `mechanism.py`. 확증 검정 군은 Holm 보정, 나머지는 BH.
4. 시드 수와 종료 규칙: **월드 수는 위 표대로 고정**하고 결과를 보고 추가하지 않는다 (기존 stopping 문제 해소).
5. 제외 규칙: API 오류·파싱 실패율이 월드당 5%를 넘으면 제외하고 제외 수를 보고한다.
6. 프롬프트 원문, 모델 버전·접근 일자, 샘플링 설정 전체를 보관한다.

## 검정력 (기존 144 월드의 로그에서 계산)

Gini의 셀 내 표준편차 풀링값은 0.0425입니다. 이를 쓰면 다음과 같습니다.

| 목표 | 필요/가능한 값 |
|---|---|
| authority 평균 효과(Gini 차이 0.026) | 집단당 43 월드면 검정력 80%. 블록 A는 집단당 108 월드라 검정력 약 99% |
| authority × rent 상호작용 | 셀당 54 월드일 때 표준오차 0.0116, 검출 가능한 최소 크기 약 0.032 |

기존 상호작용 추정치는 +0.008(95% CI −0.017~+0.033)이라 **작은 상호작용은 이 설계로도 탐지하기 어렵습니다.** P3′는 "있다/없다"가 아니라 "0.03보다 큰 상호작용이 있는가"로 진술해야 정직합니다. 더 작은 상호작용을 보려면 셀당 월드 수를 늘려야 하며, 필요 수는 목표 효과 크기를 정한 뒤 위 공식(`TTestIndPower`)으로 계산하세요.

## 비용 (기존 로그에서 계산)

- 기존 main 144 월드의 실제 비용은 합계 16.97달러로, 월드당 평균 0.118달러입니다 (Claude만 0.078, DeepSeek만 0.150, 혼합 0.126). h2 24 월드는 2.57달러입니다.
- 파일럿·smoke까지 합친 전체 지출은 약 32.95달러, 호출 79,610회입니다(`spend.json`).
- 블록 A(216 월드, 프레이밍은 비용을 거의 바꾸지 않음): 약 25달러 이상으로 추정됩니다(월드당 0.118달러 가정, 단순 외삽).
- 블록 B는 에이전트 수에 따라 호출이 선형으로 늘고 상태 프롬프트도 길어집니다. 24명 월드는 6명 월드의 최소 4배로 보면 됩니다. 추론을 켜면 출력 토큰이 크게 늘어 별도 예산이 필요합니다. 이 항목은 외삽이라 불확실합니다.
- 블록 C의 새 모델은 단가가 달라서 사전 소량 시험으로 월드당 비용을 먼저 재야 합니다.
- `llm.py`의 `AE_BUDGET_USD` 기본값 45달러가 전체 상한이므로, 본 실험 전에 올려야 합니다.
