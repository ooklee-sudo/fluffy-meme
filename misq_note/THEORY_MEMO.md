# 이론 메모 초안: 리뷰 도착을 포아송 과정으로 본 정보시스템 이론 (지도교수 면담용, 초안)

작성 상태: 초안. 모형은 의도적으로 단순하며 형식화·증명은 연구자와 함께 해야 합니다. 아래에서 "관측됨"으로 표시한 항목은 **이미 본 결과와 일치하는 것일 뿐 확인(confirmatory) 증거가 아닙니다.** "신규 예측"만 사전 등록 후 검증 대상입니다.

## 1. 기본 구조: 도착과 솎아내기
상품(식당) i의 월별 구매·방문은 비율 μ_it인 포아송 과정이고, 각 고객이 확률 p_it로 리뷰를 쓴다면(독립 솎아내기) 리뷰 도착은 비율 λ_it = p_it · μ_it 인 포아송 과정입니다.

  log λ_it = log μ_it + log p_it

- 포아송 FE 회귀의 계수는 log λ의 변화입니다. 즉 **수요 충격(μ)과 작성 충격(p)의 합**입니다.
- 상품 간 μ_i가 감마 분포를 따르면 리뷰 수는 음이항(포아송-감마)입니다. 분산 모수 α는 수요 이질성의 크기이고, 처음 원고의 과분산 진단에 이론적 해석을 줍니다.

## 2. 세 사례의 위치 (같은 틀, 다른 충격)
| 사례 | 충격이 움직이는 것 | 비고 |
|---|---|---|
| Yelp COVID | 주로 μ (방문). 포장 지향도가 높을수록 μ 하락이 작음 | 계수 +0.086은 Δlog μ와 Δlog p의 합 |
| Amazon 인센티브 금지 | 주로 p (인센티브를 받은 집단의 작성 확률) | 공개된 인센티브 리뷰가 507건에서 7건으로 감소 (측정됨) |
| Steam 키 리뷰 제외 | 키 사용자의 작성 유인(점수 가중치) | 리뷰는 남지만 점수에 영향 없음 |

한계: μ와 p를 분리하려면 판매·방문 자료가 필요합니다. 우리 데이터에는 없습니다(Yelp 방문 자료는 별도 접근 필요).

## 3. 핵심 이론 후보 A: 정보 도착률과 학습
품질 q_i를 모르는 소비자가 리뷰를 도착률 λ_i의 포아송 신호로 관찰하고 정규-정규 베이즈 갱신을 한다면, 시점 t까지 도착한 리뷰 수 N_t에 대해 사후 분산은 대략 σ²/(τ + N_t)로 줄어듭니다. 도착률이 낮아지면 N_t의 성장이 느려져 불확실성이 오래 남습니다.

**명제 1 (예측).** 충격으로 λ가 하락한 상품에서 (a) 월별 평균 평점의 분산은 1/N에 비례해 커지고, (b) 수요의 평점 민감도는 N이 작을수록 큽니다.
- 신규 예측 1 (기존 데이터로 검증 가능): Yelp COVID에서 T가 낮은(더 크게 줄어든) 식당의 **월별 평균 평점 분산이 사후에 더 크게 증가**한다. 사전 등록 대상.
- 신규 예측 2 (추가 데이터 필요): 리뷰 수가 줄어든 식당일수록 평점이 다음 기간 방문·매출에 미치는 영향이 커진다.

## 4. 핵심 이론 후보 B: 리뷰 작성의 전략적 대체성 (관측된 이상 현상 설명)
고객 j는 편익 b_j(이타성, 지위, 인센티브)와 비용 c_j를 비교해 쓰고, 편익이 이미 쌓인 리뷰 수 N에 대해 감소한다고 하자(한계 정보 가치 하락, 무임승차). 그러면 p(N)은 N의 감소함수이고 리뷰 작성은 **전략적 대체재**입니다.

**명제 2 (예측).** 인센티브 리뷰를 제거하면 N이 줄어 비인센티브 고객의 p가 올라 **유기적 리뷰가 부분적으로 대체**된다. 대체의 크기는 제거된 비중에 비례하고 쌓인 N이 클수록 작다.
- 관측됨(확인 증거 아님): Steam에서 키 리뷰는 줄고 구매 리뷰는 늘었다(+0.060, p=0.03; 플라시보 미실시). Amazon의 비플래그 리뷰 볼륨은 부호가 양(+)이나 유의하지 않고 플라시보가 실패했다.
- 신규 예측 3: 같은 효과가 **정책 이전 쌓인 리뷰 수가 적은 상품일수록 크다**(이질성). 새 데이터 또는 보류한 표본에서 사전 등록 후 검증.

## 5. 작성자 선택과 구성 효과
인센티브 리뷰 작성자가 더 긍정적이라면(업계 분석 주장, 학술 검증은 별개) 제거 후 남은 리뷰의 평균 평점은 하락한다.
- 관측됨(확인 증거 아님): Amazon에서 노출 10pp당 평점 −0.18 (이분형은 유의하지 않음). Steam에서는 긍정 비율 변화 없음(점수 제외만 있고 리뷰 풀은 유지) — 제거(Amazon)와 가중치 하향(Steam)의 대비는 사후 해석이므로 확인 필요.
- 신규 예측 4: 가중치 하향 방식에서는 풀의 구성이 유지되므로 **작성자 구성 변화가 없다**. 구성 변화를 직접 측정할 수 있는 새 데이터(리뷰어 ID가 있는 자료)가 필요하다.

## 6. 정리: 검증 대상 예측
| # | 예측 | 필요한 자료 | 상태 |
|---|---|---|---|
| 1 | λ 하락 식당에서 월별 평균 평점 분산 증가 | 현재 Yelp | 사전 등록 후 검증 가능 |
| 2 | 리뷰 수 적은 상품에서 평점→수요 민감도 증가 | 판매·방문 자료 | 자료 없음 |
| 3 | 대체 효과가 기존 리뷰 수가 적은 상품에서 더 큼 | Steam/Amazon 이질성 | 사전 등록 후 검증 가능 (단, 플라시보 실패 문제 존재) |
| 4 | 가중치 하향 방식은 구성 변화가 없음 | 리뷰어 단위 자료 | 자료 필요 |

## 7. 이 메모의 한계 (솔직하게)
- 솎아내기, 포아송-감마, 베이즈 학습은 표준 도구라 **단독으로는 새로움이 아니며**, 새로움은 명제 2(전략적 대체성)와 신규 예측의 결합에서만 나올 수 있습니다.
- 모형의 가정(독립 솎아내기, 정규-정규 학습, p가 N의 감소함수)은 검증되지 않았습니다.
- 우리의 세 실증 결과는 식별이 약하거나 예상된 것입니다. 이론이 이를 구제하지는 못하고, 신규 예측의 검증 결과에 달려 있습니다.
- 형식화(균형, 비교정학)와 선행 이론(리뷰 작성 유인, 정보 도착과 학습, 평점 시스템 설계 문헌)과의 대조는 아직 하지 않았습니다.
