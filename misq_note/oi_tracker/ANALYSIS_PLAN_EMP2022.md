# 2022 gasoline surge and state restaurant employment, driving-exposure design: analysis plan (fixed before any employment value is examined)

**Status.** Written 2026-10-14. The author dropped the Iran-war analysis and asked for the same state-level design applied to the 2022–23 gasoline surge, with restaurant employment (BLS CES via FRED) as outcome. State restaurant employment and total nonfarm series were downloaded; their values were not examined. Four states (IA, NM, SD, WV) have no NSA NAICS-722 series on FRED and are excluded (47 states; DC included if available). This employment design complements `ANALYSIS_PLAN_STATE_2022.md` (card spending), whose results are in `RESULTS_STATE2022.md`.

**Data.** FRED `SMU{FIPS}000007072200001` (food services and drinking places employment, NSA, thousands, monthly) and `{ST}NA` (total nonfarm, NSA); exposure E1 = 2019 VMT per resident (FHWA Table VM-2 2019 / FRED `{ST}POP` 2019), standardized; E2 = 2019 poverty rate (FRED SAIPE), standardized. Gas: FRED GASREGW averaged by calendar month, ln. Window: 2021-09 to 2023-12 (after the main COVID reopening; ends before the 2024 slowdown).
**Model.** ln Y_st = α_{s,m(t)} + γ_t + δ_s·t + β·(E_s × G_t) + e_st; α_{s,m} state × calendar-month effects (seasonality), γ_t year-month effects (absorb G_t and all national shocks), δ_s state-specific linear trends, cluster by state; randomization-inference p from 5,000 permutations of E across states.
**Hypotheses.** H_E1 (primary, directional): β < 0 for restaurants with E1 (higher-driving states lose more restaurant jobs when gasoline is expensive). H_E2 (specificity): β on total nonfarm employment is smaller in magnitude; and on the restaurant share ln(restaurants) − ln(nonfarm). H_E3: the same with poverty E2.
**Checks.** (i) lags: G averaged over the previous 3 months instead of the current month; (ii) no state trends; (iii) drop the five largest states by restaurant employment; (iv) window 2022-01..2023-12; (v) placebo: use gasoline shifted 24 months earlier (2019–2021 path) in the same window (should give no effect).
**Interpretation.** H_E1 supported only if β < 0, cluster p < 0.05, permutation p < 0.10, and placebo not significant with the same sign. Limitations: employment responds slowly to demand and reflects labor supply (2022 labor shortages); post-COVID recovery trends differ by state (partly absorbed by state trends); 47 states; VMT is correlated with rurality and region.
