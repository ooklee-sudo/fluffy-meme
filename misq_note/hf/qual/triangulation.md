# 삼각검증 요약 (20건) — 원자료: triangulation_A.json, triangulation_B.json

조사 방식: 에이전트 2개가 게시 시각·본문만 받아(우리 반응값 비공개) 독립 보도를 수집. 한계: CNBC·CNN·Axios 등은 403/429로 직접 열람 불가, WebFetch는 페이지 요약을 반환하므로 인용은 근사치, 유가 시황 기사 다수가 Bloomberg(Rigzone 재게재)에 의존해 출처 독립성이 제한적. 우리의 정량 반응은 게시 시각을 포함한 **시간봉 반응**이고 보도는 **일별 종가 변화**를 쓰는 경우가 많아 수치가 직접 일치하지 않는다(예: C13 일별 WTI +0.73%, 우리 시간봉 −1.4%).

아래 분류(A/B/C)는 에이전트 메모를 읽은 **연구자의 해석**이며 동료 검토 대상이다.
- A = 게시물이 결정의 최초 공개 발표(보도가 게시물 내용을 시장 움직임의 원인으로 명시)
- B = 게시물 외 다른 사건이 보도의 주된 원인(게시물 미언급 또는 게시 시각이 마감 후)
- C = 링크/재게시 등 새 정보가 없는 게시물

## 집계
- 20건 모두 게시물 외 다른 원인이 보도에 존재한다.
- 게시물 자체를 시장 기사가 다룬 것: 13건. 다루지 않은 것: 7건(C04, C09, C10, C11, C16, C19, C20).
- A(결정의 최초 발표) 5건(C01, C02, C03 일부, C05, C08), C(링크/재게시) 4건, 나머지 B.
- 상위 8건 중 최소 4건(C01, C02, C05, C08)은 게시물이 곧 결정 발표다.
- 부분 검증: C04, C18. 간접 출처 의존: C06, C07, C08, C10.
