# 질적 명제 검정 결과 (사전 등록: ANALYSIS_PLAN_QUAL_TESTS.md, 코드: analysis_qual_tests.py, 원자료: results_qual_tests.json)

## Q1 (운반체: 재게시·링크는 반응이 없고 원본 발표에서 반응이 크다) — **지지되지 않음**
의사 외표본 134건(OOT 일별 반응 + 연준·중국 주제 시간봉 반응; 18건은 반응값 결측으로 제외). 분류: ORIG 111, AMP(RT·링크) 23. 계획서의 예상(AMP 약 24, ORIG 약 126)보다 ORIG가 적은 것은 결측 때문이다.

| 항목 | 값 |
|---|---|
| 평균 estd, ORIG | +0.03 |
| 평균 estd, AMP | +0.16 |
| 차이(ORIG−AMP) | −0.13 (95% CI −0.57 ~ +0.31) |
| 단측 순열 p (H_Q1a) | 0.76 |
| AMP 평균의 0 검정 (H_Q1b) | 양측 p=0.38, CI −0.19 ~ +0.52 |
| 최소검출효과(80%, 단측 .05) | 0.75σ (계획서의 약 0.5σ보다 컸음; 결측 때문) |

- 사전 판정 규칙: 점추정치가 0 이하이므로 '지지되지 않음'.
- 해석 단서: 신뢰구간이 +0.31σ 넘는 'ORIG 우위'는 배제하지만 작은 우위는 배제하지 못한다. 그리고 ORIG 평균 자체가 0과 거의 같다(+0.03). 이 외표본에서는 원본 게시물도 평균적으로 뚜렷한 방향 반응이 없어서, 재게시와 구별할 대상이 없었다.
- 층별 평균은 방향이 일관되지 않는다(OOT 관세: ORIG −0.19 vs AMP +0.07, OOT 원유: ORIG +0.33 vs AMP +0.14 등, AMP n은 2~14). ORIG 중 ACTION만(n=25) 평균 +0.22.
- 따라서 Q1의 질적 근거(삼각검증에서 링크·재게시 4건에 반응 없음)는 외표본에서 재현되지 않았다. 더 정확히는, 이 표본의 재게시·링크가 모두 '뉴스가 없는' 사례는 아니었다.

## Q4 (시계: 마감 후 게시물은 재개장 반응이 더 선명하다) — **표본 내 탐색적 측정 분석, 지지되지 않음**
`paper_signal_posts` 원유 신호 중 시간봉 정렬 가능 118건; 정규장 밖 게시 61건.

| 항목 | 값 |
|---|---|
| 정규장 밖 61건: 즉시 반응 평균 | +0.65% |
| 같은 61건: 재개장(다음 평일 09:00 ET 봉 종가) 반응 평균 | +0.55% |
| 차이(재개장−즉시) | −0.10% |
| 단측 대응 부호반전 순열 p | 0.63 |

- 재개장 반응이 더 선명하다는 예측과 반대 방향이며 유의하지 않다. 측정 창이 길어질수록 다른 뉴스가 섞여 효과가 흐려질 수 있다는 단서가 있다.
- 부수 관찰(탐색적, 결과를 본 뒤 읽음): 정규장 밖 게시물의 즉시 반응(+0.65%)이 정규장 안 게시물(n=57, +0.26%)보다 크다. 얇은 시장에서의 반응 크기이거나 정규장 밖에 결정적 발표가 몰린 효과일 수 있고, 어느 쪽인지는 이 자료로 알 수 없다.

## 종합
- 질적 단계에서 도출한 명제 중 검정 가능했던 Q1과 Q4는 모두 지지되지 않았다. Q2와 Q3는 전향 수집 프로토콜만 등록되어 있다(계획서 참조).
- 이는 이전 세 이론의 결과와 같은 방향이다. 질적 읽기에서 보인 패턴(T1~T5)은 20건 삼각검증의 사례 수준 설명으로는 유효하지만, 일반 규칙으로는 아직 입증되지 않았다.
- 논문에서의 위치: T1~T5와 Q1~Q4는 '귀납적으로 도출했고 외표본 검정에서 확증되지 않은 가설'로 보고하고, 본문은 기술적 결과(포아송-감마 도착, 코딩 신뢰도, 봉쇄 국면의 상태 의존 반응)와 부정 결과를 중심으로 쓰는 것이 증거와 맞다.
