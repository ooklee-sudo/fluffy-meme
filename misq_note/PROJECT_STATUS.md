# 프로젝트 현황 (지도교수 면담용, 2026-10-13 기준)

**한 줄 요약.** 리뷰 도착을 포아송 과정(λ = p·μ)으로 보고 플랫폼 거버넌스·외생 충격이 리뷰 공급에 미치는 영향을 사전 등록 방식으로 검증해 왔다. 4개 사례 중 결과가 가장 깨끗한 것은 Yelp COVID(예상된 방향)이고, 나머지는 약하거나 영 결과다. 이론 메모(`THEORY_MEMO.md`)의 신규 예측 검증과 사람 코딩이 남아 있다.

## LLM 코딩 신뢰도 (Amazon, 399쌍)
κ: 전체 감성 0.92, 결함 0.92, 가격 0.98, 내구성 0.93, 성능 0.87, 적합성 0.84, 사용편의 0.85, 디자인 0.79, 서비스 0.89; 별점과 Spearman 0.77. **사람 코딩 대조는 없음**(150건 blind 시트 `study3/human_coding_sheet.xlsx` 대기).

## 이론 (`THEORY_MEMO.md`)
- λ = p·μ 분해, 포아송-감마(음이항), 정보 도착과 학습, 리뷰 작성의 전략적 대체성(Steam 구매 리뷰 +0.060과 방향 일치하나 사후 해석).
- 신규 예측 4개: (1) λ 하락 식당에서 평점 분산 증가 → Yelp에서 검증됨(약한 지지, 강건성 혼재); (2) 평점→수요 민감도(판매·방문 자료 필요); (3) 대체 효과가 리뷰 수 적은 상품에서 더 큼; (4) 가중치 하향 방식은 구성 변화 없음(리뷰어 단위 자료 필요).

## 데이터 접근 점검 결과
영어권 공개 데이터 외에는 "날짜가 있는 개별 리뷰 + 규제 충격" 조합을 찾지 못함. 일본 Rakuten(NII)은 일본 소속 연구자 한정·기간 확인 필요, 한국·싱가포르·홍콩·멕시코·캐나다는 막힘, 호주 SNS 연령 제한은 리뷰와 불일치. Mendeley 배달앱 데이터는 날짜 열 없음.

## 즉시 필요한 결정과 일
1. **사람 코딩 150건** (코더 2명): LLM 측정의 타당성 확보에 필수.
2. **이론 예측 3 사전 등록**(Steam/Amazon 이질성)과 Yelp P1 후속(노출 정의 민감도 정리).
3. **Yelp LLM 코딩**(안전·위생, 포장·배달, 서비스 언급): 이론 방향 확정 후 진행.
4. Inside Airbnb 다음 스크랩(2026-11~12)에서 유가 충격 확인(confirmatory) 재검정.
5. 투고 층위 판단: 현재 자료로 MISQ는 어렵다는 평가 유지. 이론 검증 결과(예측 3, 예측 1의 강건성)와 사람 코딩이 갖춰진 뒤 재평가.

## 결과 해석 시 주의
- "사전 등록 검정"과 "탐색적(사후)" 분석을 반드시 구분해 보고한다. 유가 연구의 초기 공항 거리 결과처럼 사후 분석에서 나온 유의성은 도시별 확인에서 사라질 수 있다.
- 플라시보가 실패한 결과(Steam 볼륨, Amazon 볼륨, 저가 숙소)는 인과 해석 불가.
- 이름이 같은 파일의 군집 표준오차 이슈(`oil/analysis_oil_exploratory2.py`의 도시 단위 열)는 사용하지 않는다.
