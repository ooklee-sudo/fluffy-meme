# 확장안: 내생적 제품화율 η와 계약 보호 (Proposition 5 심화)

상태: 설계안. 논문 본문(`manuscript.md`)에는 아직 넣지 않았다. 아래 수식은 수치로 검증했다(무작위 파라미터 3,000회, 닫힌 해를 격자 탐색과 비교).

## 1. 설정

기존 모형에서 Prop 5는 제품화율 η를 외생으로 두었다. 여기서는 개발자가 η를 고른다.

- 채택자의 보완 지대 흐름: R = (p − c_j) q_j.
- 경쟁자의 모방: 확정적 지연 τ_O 대신 도착률 μ인 지수 분포로 바꾼다(평균 지연 1/μ). 이는 닫힌 해를 얻기 위한 단순화이며, Prop 2와 Prop 5의 비교정태는 그대로다. 기대 지대는 R/(ρ + μ + η) − g(O_j)가 된다. 아래에서 r ≡ ρ + μ.
- 계약 보호 s ∈ [0, 1): 데이터 사용 제한, 미세조정 소유권, 온프레미스 배치 등 개발자가 사용 정보를 제품화에 쓰지 못하게 막는 정도. 개발자의 노력 e는 η = (1 − s)e 의 비율로만 제품화율이 되고, 노력비용은 (k/2)e². 따라서 제품화율 η를 얻는 비용은 (K(s)/2)η², K(s) = k/(1 − s)² 이며 s에 대해 증가한다.
- 제품화에서 개발자가 얻는 현재가치: G = φR/r. φ ∈ (0, 1]은 채택자 지대의 현재가치 R/r 중 개발자가 가져가는 몫이다(나머지는 소비자로 간다).

개발자는 제품화나 모방이 먼저 일어날 때까지 노력비용을 내면서 다음을 최대화한다.

J(η) = (Gη − Kη²/2) / (r + η)

## 2. 결과

**Proposition 6 (균형 제품화율).** 유일한 내부해가 있고

η* = −r + √(r² + 2Gr/K).

η*는 G (따라서 R과 φ)에 대해 증가하고, K (따라서 s)에 대해 감소한다. G를 고정하면 r에 대해 증가한다. 즉 모방이 빠를수록(μ↑) 개발자는 제품화를 서두른다. 모방과 제품화는 전략적 보완 관계다.

*증명 요지.* 일계조건 (G − Kη)(r + η) − (Gη − Kη²/2) = 0 은 η² + 2rη − 2Gr/K = 0 으로 정리된다. 양의 근이 하나이고, J(0) = 0, J′(0) > 0, η → ∞에서 J → −∞ 이므로 내부 최대다. 비교정태는 근의 공식에서 바로 나온다. r에 대해서는 ∂η*/∂r = −1 + (r + G/K)/√(r² + 2Gr/K) 이고, (r + G/K)² > r² + 2Gr/K 이므로 양수다. 최적에서 J* = G − Kη* 이다(일계조건).

**Proposition 7 (계약 보호와 보완 투자).** 채택자의 기대 지대 R/(r + η*(s)) − g(O_j)는 s에 대해 증가한다. 따라서 보완자본 투자 조건 R/(r + η*) ≥ g(O_j)를 만족하는 O_j의 범위는 s가 커지면 넓어진다. 보호 없이는 투자되지 않았을 보완자본이 보호가 있으면 투자된다.

*증명 요지.* Prop 6에서 η*가 s에 대해 감소하고, R/(r + η)는 η에 대해 감소한다. 투자 조건은 지대의 현재가치를 비용과 비교한 것이다. 이는 hold-up 논리(Klein, Crawford, and Alchian 1978; Grossman and Hart 1986)를 LLM 공급 관계에 적용한 것이다.

## 3. 수치 예시: 보호 계약은 가치가 큰 용도에서 성립하지 않는다 (명제 아님)

채택자가 보호에 지불할 의사 WTP = R/(r + η*(s₁)) − R/(r + η*(s₀)) 와 개발자의 손실 K₁η₁ − K₀η₀ (J* = G − Kη* 에서 나옴)를 비교한다. 파라미터 r = 0.3, φ = 0.8, k = 1, s: 0 → 0.5.

| R | η*(s=0) | η*(s=0.5) | WTP | 개발자 손실 | 계약 성립 |
|---:|---:|---:|---:|---:|:---|
| 0.5 | 0.643 | 0.239 | 0.398 | 0.311 | 예 |
| 1 | 1.000 | 0.400 | 0.659 | 0.600 | 예 |
| 2 | 1.514 | 0.643 | 1.017 | 1.060 | 아니오 |
| 4 | 2.248 | 1.000 | 1.507 | 1.752 | 아니오 |
| 8 | 3.290 | 1.514 | 2.182 | 2.765 | 아니오 |

이 파라미터에서는 지대가 큰 용도일수록 개발자가 제품화로 얻는 몫이 커서 보호를 팔 값이 WTP를 넘는다. 즉 보호는 시장에서 가치가 작은 용도에서만 거래되고, 가장 가치 있는 용도는 보호받지 못한다. 이 결과는 파라미터에 의존한다(무작위 20,000회 중 약 5%에서 WTP < 손실). 일반 명제로는 증명하지 못했고, 본문에 넣는다면 "수치 예시"로만 써야 한다.

## 4. 한계와 주의

- η는 여전히 상수 비율이고 개발자 한 명이 일방적으로 정한다. 개발자 간 경쟁(여러 벤더가 같은 용도를 노림), 채택자의 대응(용도를 숨기거나 다른 벤더로 이동), 협상은 모형에 없다.
- K(s) = k/(1 − s)² 는 편의적 함수형이다. 보호가 노력의 효과를 줄이는 방식(η = (1 − s)e)에서 나온 것으로, 법적 제약을 다른 방식으로 모형화하면 결과가 달라질 수 있다.
- φ와 G = φR/r 는 환원형이다. 제품화 후 개발자가 어떻게 이윤을 얻는지(경쟁 벤더의 존재 등)는 모형화하지 않았다.
- 실증적 검증 수단이 없다. 계약 조건 자료는 공개돼 있지 않다.
- 본문에 넣으면 Prop 5의 증명(확정적 τ_O)과 지수 모방 가정이 섞인다. 정직한 처리 방법은 §4.5를 확장 절로 따로 두고 "이 절에서만 모방을 지수 분포로 둔다"고 명시하는 것이다.
