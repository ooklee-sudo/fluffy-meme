# 직무·권한 확인 문항 (전문직 패널용)

Prolific의 기본 필터(고용 상태, 현재 직무 등)는 **자기보고**로 간주하고, 아래 문항으로 설문 안에서 자격을 다시 확인한다. 문항은 한 번에 보여주되 자격 기준은 응답자에게 알리지 않는다. 영어 원문으로 배포하고 한국어 대조본을 둔다. 척도 문구는 파일럿에서 다듬는다.

## 선별 문항 (본 설문 시작 직후)

**S1. 현재 주된 직무 기능 (하나 선택)**
1. IT / 소프트웨어 / 기술 운영
2. 데이터 / 분석 / AI·머신러닝
3. 정보보안 / 개인정보 / 컴플라이언스
4. 조달 / 구매 / 벤더 관리
5. 재무 / 경영 기획
6. 경영 일반 (대표, 사업부 책임자 등)
7. 그 밖의 직무 → **비적격**
8. 현재 근무하지 않음 → **비적격**

**S2. 직급 (하나 선택)**
1. 일반 실무자 2. 팀 리더 3. 매니저 4. 디렉터 5. 임원(VP 이상) 6. 소유주/대표

**S3. 조직의 기술·벤더 도입 결정에서 나의 역할 (하나 선택)**
1. 최종 결정을 내린다
2. 최종 결정은 아니지만 내 권고가 사실상 결정한다
3. 의사결정 위원회/팀의 구성원으로 참여한다
4. 의견만 제공한다
5. 관여하지 않는다 → **비적격**

**S4. 혼자 승인할 수 있는 연간 기술·소프트웨어 예산 규모 (하나 선택)**
1. 없음 2. USD 1만 미만 3. 1만–10만 4. 10만–100만 5. 100만 초과

**S5. 근무 조직 규모 (직원 수)**
1. 10명 미만 2. 10–49 3. 50–249 4. 250–999 5. 1,000 이상

**S6. 최근 2년간 AI/LLM 서비스(API, 클라우드 도구 등)의 **도입 여부 결정**에 관여한 경험**
1. 없음 2. 논의에 참석한 적 있다 3. 후보를 평가한 적 있다 4. 결정에 직접 참여했다

**S7. 클라우드 서비스와 자체 서버(온프레미스)의 차이에 대한 익숙함 (1 매우 낯섦 – 5 매우 익숙)**

## 자격 규칙 (사전등록)

**적격 = S1 ∈ {1–6} AND S3 ∈ {1,2,3} AND (S2 ≥ 3 OR S4 ≥ 3 OR S3 ∈ {1,2}) AND S6 ≥ 2 AND S5 ≥ 2**

- 위 규칙을 충족하지 못하면 설문을 중단하고 Prolific의 스크린아웃 절차에 따라 처리한다(보상 규칙은 §9 확인 후 확정).
- S3 ∈ {3}만 충족하는 경우에는 S2 ≥ 3 또는 S4 ≥ 3이 함께 있어야 한다.

## 일관성·품질 점검

- **C1 (설문 끝)**: S1과 S2를 다시 묻고 **불일치 시 제외**.
- **A1, A2 주의 점검**: "이 문항에서는 '약간 동의'를 선택하세요" 형태로 본문 사이에 2개. **1개라도 틀리면 제외**.
- **K1, K2 시나리오 이해 점검**: 각 시나리오 직후, "로컬 구축의 일회성 비용은 얼마인가" 같은 사실 확인 1문항을 시나리오마다 두고, **전체 4개 중 2개 이상 틀리면 제외**.
- **시간 점검**: 중앙 소요 시간의 1/3 미만이면 제외.
- **무성의 응답**: F_max 슬라이더 값이 4개 시나리오에서 모두 동일하고 선택도 모두 같으면 제외.
- **음성 대조(선택)**: "다음 중 실제 LLM 서비스가 아닌 것은?" 같은 문항으로 허위 경력 응답 탐지.

## 기록해 둘 것

- 필터 통과 인원, 선별 통과/탈락 인원, 제외 사유별 인원을 모두 기록해 논문에 표로 보고한다.
- 직무·직급·권한은 응답자 특성 표로 보고하고, 주 분석의 공변량으로도 사용한다.
