# ISR submission files

| File | What it is | Upload as |
| --- | --- | --- |
| 0_Title_Page (.docx/.pdf) | Title, author, affiliation, contact, funding, conflicts, AI-use disclosure | Title page (not sent to reviewers) |
| 1_Manuscript_anonymized (.docx/.pdf) | Blinded main text with Figures 1–5, Tables 1–16, references | Main document |
| 3_Online_Appendix (.docx/.pdf) | Appendix A (proofs), Appendix B (data and replication) | Online appendix / supplemental file |
| 4_Cover_Letter (.docx/.pdf) | Letter to the Editor-in-Chief | Cover letter |
| replication_package.zip | Code, small datasets, README mapping scripts to tables/figures | Supplemental file (or keep for acceptance) |
| figures/ | Figures 1–5 as 300-dpi PNG, plotted values, plotting script | Separate figure files if requested |

## Before uploading
1. Fill every [bracketed] placeholder in the title page and cover letter (name, department, date, funding, AI-use disclosure).
2. Check the blinded manuscript and appendix for any self-identifying text (file properties too: in Word, File > Info > Inspect Document).
3. Verify the reference titles marked as descriptive in the review notes (Google 2024a, 2025b–d; Android Authority 2024; Search Engine Land 2024; Exploding Topics 2025) and obtain the original Agarwal & Sen (2026) paper.
4. Edit the .docx files if you change text, then re-export PDFs from Word (Word renders the equations correctly).
